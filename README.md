## “双 ISP 住宅 IP”是什么，到手机器怎么验

平台风控看的是 IP 在数据库里的属性。数据中心 IP 会被标记为商业或机房用途，TikTok、Shopify、Amazon 这类平台对它的审核权重更高；住宅 IP 在数据库里对应的是英国家庭宽带运营商分配出去的地址。

完整的双 ISP 要两个维度同时成立：Company 类型显示为 ISP，ASN 类型也显示为 ISP。只满足一个维度，有可能是拿广播段伪装出来的住宅属性。判断真假时不要只看商家截图，到手后用 ipinfo、Scamalytics、ping0 三个工具交叉查一遍。

## 常见问题

**英国双 ISP 住宅 IP VPS 和普通英国 VPS 差在哪？**
普通英国 VPS 拿到的是机房 IP，数据库里标记为数据中心；双 ISP 住宅 IP 来自 Sky 这类家庭宽带运营商的地址段，平台风控对两者的处理方式不同。需要模拟英国本地用户环境时才值得为此付溢价。

**国内访问速度怎么样，一定要中转吗？**
平均约 216ms，联通和部分地区移动直连可用，电信偏高。官方建议香港或日本中转并开启 BBR，做实时操作（直播后台、多窗口管理）建议直接配中转。

**真的能看 BBC iPlayer 吗？**
官方支持列表里有，第三方测评也记录过成功解锁。前提是英国本土住宅 IP，实际以你当前拿到的 IP 为准。

**基础版够用吗？**
单人运营一到两个英区账号、日常浏览和上传，1 核 1GB 加 6TB 流量够。要同时跑多个账号环境或做批量任务，再考虑进阶版。

**IP 被运营商收回怎么办？**
提工单处理。住宅 IP 市场无法完全避免这种情况，重要业务要提前准备备用节点。

**支持 Windows 吗？**
官网英国产品页写明支持 Linux 和 Windows 安装。美国套餐装 Windows 需要工单，两个地区流程不同，下单前按自己要买的地区确认。

**新机器连不上是什么原因？**
先查 SSH 端口。默认不是 22，是随机端口，在管理面板里能看到实际端口号。
